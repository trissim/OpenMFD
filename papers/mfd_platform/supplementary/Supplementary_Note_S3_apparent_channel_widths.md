# Supplementary Note S3 — Apparent microchannel widths in cast devices

Brightfield images supplied nine apparent width observations: three channel positions in one device from each of the three plates. Figure S3 shows device R02C02 from Plate 1 (left), Plate 2 (centre) and Plate 3 (right). Distances were read between the centres of opposing dark wall bands using the native image calibration of 1.18675253 µm per pixel. The observed spans were 9–11 pixels, equivalent to 10.7–13.1 µm. Supplementary Data S4 provides the full-precision values, pixel coordinates, calibration and recorded placement notes.

The apparent widths depend on where the wall-band centres are placed. Moving each endpoint by one native pixel can change a span by up to two pixels, or 2.37 µm at the recorded calibration. This is a placement-sensitivity calculation, not an error bound on the true physical width. The offset between a visible dark band and the physical channel wall was not quantified. Channel depth and the full cross-sectional profile were not measured.
